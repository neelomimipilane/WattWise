# Watt-Wise

**Know Your Power** — Botswana-focused solar sizing and energy planning.

## Stack

- React
- JSX / TypeScript
- Tailwind CSS
- Lucide React icons

## Run

```bash
npm install
npm run dev
```

## Workflow

Choose Profile → Add Appliances → Adjust Usage → Select Location → Generate Solar System → Estimate Cost → Compare Installers
